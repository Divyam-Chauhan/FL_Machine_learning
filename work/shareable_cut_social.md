# Shareable cut: social post

Could a model help decide which eligible search-content items to review first?

On 39,545 ML-07-eligible page-client items, an L2 Logistic Regression ranked the observed April impression-decline proxy better than the specified March-impressions rule in five client-grouped folds. Fold-macro Precision@50 was **0.804 vs. 0.420**—a 0.384 absolute difference, or about 1.9× the rule—with the model higher in all five folds.

This is one retrospective March/April cohort, selected in part using April GSC coverage. It is decision support for human review, not a live March queue, a stale-page detector, or evidence that refreshing a page restores traffic.
