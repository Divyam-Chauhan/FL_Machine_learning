# Shareable cut: social post

FlyRank's Lane 2 content-opportunity problem is deciding which high-impression, low-CTR pages deserve a human's next look. I compared an L2 Logistic Regression using March-only features with the transparent ML-07 March-impressions rule across five client-grouped folds, calculating each metric within its held-out fold. On the 39,545-item selected pool, fold-macro P@50 was 0.804 vs. 0.420 (a 0.384 absolute difference, about 1.9x), and the model was higher in all five folds. This is one retrospective March/April cohort, selected partly using April GSC coverage; it does not show that a page is stale or that a refresh recovers traffic. [Read the case study](https://divyam-chauhan.github.io/FL_Machine_learning/).
